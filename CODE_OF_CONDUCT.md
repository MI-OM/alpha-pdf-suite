# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct, for everyone who takes part: in issues, pull requests, discussions and any other project space.

## Reporting

**Contact:** to be published by the maintainer before outside contributions open. Until then, raise a concern privately with the maintainer through their GitHub profile. Do not use a public issue.

Reports are handled confidentially. The Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban) apply.

Adopted 2026-11-11 (decisions for review, Q3).
